# 🛍️ Customer Shopping Behavior Analysis

An end-to-end Data Analytics project that analyzes customer shopping behavior using **Python**, **MySQL**, and **Power BI**. The project focuses on uncovering purchasing patterns, customer segmentation, product performance, and business insights through data cleaning, SQL analysis, and interactive visualizations.

---

## 📌 Project Overview

Retail businesses generate large volumes of customer transaction data every day. This project aims to transform raw shopping data into meaningful business insights by following the complete data analytics pipeline.

The workflow includes:

- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- SQL Business Analysis
- Interactive Power BI Dashboard
- Business Presentation

The final dashboard enables stakeholders to analyze customer demographics, purchasing behavior, subscription trends, shipping preferences, product performance, and revenue contribution.

---

# 💡 Key Business Insights

- Clothing generated the highest revenue among all categories.
- Young Adults contributed the highest overall revenue.
- Only around one-fourth of customers were subscribers.
- Express Shipping customers spent slightly more per purchase than Standard Shipping customers.
- Accessories generated strong revenue despite fewer purchases.
- Discounted products were not always the highest revenue generators.
- Repeat buyers showed higher subscription tendencies.
